Cadastre sua competição

Cada competição tem seus próprios times, competidores, chaveamento e rankings. Você pode criar quantas quiser.

Dados da competição

As batalhas são individuais, mas os pontos vão para o time do competidor. O time em 1º no ranking é o campeão.

Novo time

Nome e cor do time (a cor aparece no telão).

Times cadastrados

Excluir um time também remove seus competidores.

Adicionar competidores

Cada competidor pertence a um único time. Um time pode ter vários competidores.

Competidores por time

Clique 2 vezes no nome para editar. Use o seletor ao lado para trocar de time.

Tabela e árvore mata-mata

Gere os confrontos por sorteio e sorteie novamente quantas vezes quiser. Depois, clique no nome do vencedor de cada batalha para avançá-lo (clique de novo para desfazer).

Trocar senha

Troque a senha do seu usuário admin. Novos admins são criados na tela de login, em "Criar acesso de admin", com a senha master.

Backup dos dados

Exporte tudo (todas as competições) em um arquivo JSON. No modo local, você pode restaurar a partir desse arquivo.
